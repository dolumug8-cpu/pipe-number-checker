# 관로번호 검사 프로그램

## 기능
- 엑셀에서 `관로번호`라는 셀을 찾아 그 열의 관로번호를 읽습니다.
- 선택한 동영상 폴더(기본 설정은 하위 폴더 포함)에서 동영상 파일명을 검사합니다.
- 파일명 시작 부분의 `숫자` 또는 `숫자-숫자`를 관로번호로 인식합니다.
  - `202101900 6.5M.mp4` → `202101900`
  - `202101900(영상관로번호류).mp4` → `202101900`
  - `202101900-1 9M.mp4` → `202101900-1`
- 관로번호별 동영상 개수를 집계합니다.
- 결과 엑셀에는 `전체 검사 결과`, `영상 없는 관로`, `영상 여러 개`, `엑셀에 없는 영상`, `번호 추출 불가 영상`, `검사 정보` 시트가 생성됩니다.
- 원본 엑셀과 동영상은 수정하거나 삭제하지 않습니다.

## 실행 방법 (Python)
1. Windows에 Python 3.10 이상을 설치합니다. 설치 화면에서 `Add Python to PATH`를 체크하세요.
2. 이 폴더에서 `install_requirements.bat`를 실행합니다.
3. `관로번호_검사프로그램.py`를 더블클릭하거나 `run_program.bat`를 실행합니다.

## EXE 만들기 (Windows)
1. `install_requirements.bat`를 실행합니다.
2. `build_exe.bat`를 실행합니다.
3. 완성 파일은 `dist\관로번호_검사프로그램.exe`에 생성됩니다.
4. 다른 PC로 옮길 때는 EXE 파일을 전달하면 됩니다. 첫 실행 시 Windows 보안 경고가 나타날 수 있습니다.

## 주의
- 엑셀은 `.xlsx` 또는 `.xlsm` 형식을 지원합니다. `.xls` 파일은 먼저 Excel에서 `.xlsx`로 저장해 주세요.
- `관로번호`라는 헤더 이름이 정확히 있어야 합니다.
- 관로번호는 숫자 및 `숫자-숫자` 형식으로 인식합니다. 선행 0이 중요한 경우 엑셀에서도 텍스트 형식으로 저장하는 것이 안전합니다.
- 결과 파일은 원본 엑셀과 다른 경로/파일명으로 저장하세요.
